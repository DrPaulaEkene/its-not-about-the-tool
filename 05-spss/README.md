# SPSS

**Contribution: it says whether a difference is real, in language a journal would accept.**

**The sex gap.** Male against female rates, paired by region: a mean difference of 9.7 per 100,000, t(8) = 18.0, **p < .001**. If men and women really had the same rate, a gap this size in all nine regions would almost never happen by chance.

**The deprivation gradient.** Linear regression of rate on quintile: men fall about **6.3 per 100,000** per step towards the least deprived fifth (R² = 0.91); women about **2.5** (R² = 0.94). That turns "there is a gradient" into "here is how steep it is".

**An analysis deliberately not run.** Clustering nine regions would have produced groups that were an artefact of having nine points rather than a finding. It belongs on the Local Authority file, where there are 300-plus rows.

**Honest limitation.** These are areas, not people. An association at area level does not transfer to individuals.
